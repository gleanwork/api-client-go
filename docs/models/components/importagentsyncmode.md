# ImportAgentSyncMode

Whether the imported version is staged (saved without updating the live version) or published directly to the live version.


## Example Usage

```go
import (
	"github.com/gleanwork/api-client-go/models/components"
)

value := components.ImportAgentSyncModeStaged
```


## Values

| Name                           | Value                          |
| ------------------------------ | ------------------------------ |
| `ImportAgentSyncModeStaged`    | STAGED                         |
| `ImportAgentSyncModePublished` | PUBLISHED                      |
