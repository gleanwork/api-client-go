# PlatformAgentUpdateRequest

Agent fields to change. At least one field is required. Each supplied field replaces its saved value, and arrays and objects are replaced whole. Omitted fields keep their saved values. Send an empty string or array to clear a field, `{}` to clear `channels` or reset `model` to defaults, and `null` to turn off Glean Search. `use_agent_identity` is set at creation and cannot be changed.
